## 1. Channel ranking (verified active, best-first)

### ⭐ 1. Direct barter + commission micro-influencers (TikTok/Instagram)
- **Who:** Beauty/skincare/desi-totkay creators, 5k–100k followers, Pakistani
  audience, Urdu/Roman-Urdu comments, engagement 3%+.
- **Find them:** search `#skincarepakistan #pakistaniskincare #desitotkay
  #totkay #karachiblogger #lahoreblogger`; free lists: modash.io / heepsy.com /
  clickanalytic.com (Pakistan beauty). Many bios say "DM for PR".
- **Offer:** free 50ml bottle (barter) + unique code (e.g. `AYESHA150`) =
  customer Rs 150 off, creator Rs 250/450 per DELIVERED order. No upfront cash;
  upgrade proven sellers to paid posts later.
- **Cost:** one bottle COGS + commission per sale only. (Cash-per-post market
  rate if ever needed: Rs 5–15k for 5–10k followers, Rs 10–40k for 10–20k.)
- **Vetting:** views ≥ 10–20% of followers; real Urdu comments (not emoji
  bots); ask for screen-recorded audience insights (city/gender) before
  sending product; agree posting date in writing (WhatsApp).

### ⭐ 2. Facebook reseller groups → own WhatsApp reseller network
- **How low-ticket COD actually moves in Pakistan:** housewife/home-based
  resellers on Rs 300–500 margin per unit; you book every parcel (customer
  data stays yours), payout via Easypaisa after delivery.
- **Groups (verified):** "Ecommerce Success" (Huzaifa Ali), SkillsPanda
  "Pakistan Ecommerce", Extreme Commerce community, PECC. Search terms:
  "reseller required Pakistan", "home based business ladies Pakistan",
  "online sellers Pakistan".
- **Pitch post:** product photos + reseller price (e.g. Rs 1,400 on the
  Rs 1,800 SKU) + "aap ka profit aap ki marzi" + hum pack/COD courier karte
  hain + margin Easypaisa se delivery ke baad.
- **Cost:** free (ignore Rs 500–2,000 "pinned post" upsells).

## 2. Program design (is hafte launch — zero new software)

### Commission
- **Flat per DELIVERED order:** Rs 250 (50ml) / Rs 450 (100ml) ≈ 14–15%.
- Customer sweetener: code = **Rs 150 off** (code entry hi tracking hai).
- Total cost delivered 50ml par: Rs 400 (22%) — Meta-ads CAC (Rs 800–1,500)
  se kaafi sasta. Tight margin ho to Rs 200 + Rs 100 off; **Rs 150 commission
  se neeche kabhi nahi** (interest khatam ho jata hai).
- Delivered-only rule = affiliate COD-refusal risk share karta hai.

### Tracking (existing admin + 1 Google Sheet)
1. Har affiliate ka ek coupon: fixed Rs 150 off, no expiry — naam pattern
   `NAME150` (AYESHA150, BILAL150). **Code hi tracking hai.**
2. "Affiliate Ledger" sheet: Order #, date, code, item, courier status,
   Delivered date, **Eligible date = Delivered + 7 din buffer**, commission,
   Paid Y/N, ref.
3. Har Monday 15 min: admin order list ko code se filter → sheet update.
4. Returned/refused = Rs 0. Kabhi pehle pay karke wapas nahi mangna —
   **late pay > clawback**.
5. UTM link backup attribution ke liye (GA4), lekin rule: **no code on order
   = no commission** (48h claim window agar customer code bhool jaye —
   phone number se verify).
6. Monthly statement: us affiliate ki filtered rows ka screenshot WhatsApp
   par (customer data kabhi nahi).

### Payment
- Monthly, 1–5 tareekh, pichle mahine ke eligible orders.
- JazzCash/Easypaisa default (CNIC-matching name signup par lein);
  IBAN sirf Rs 25,000+ par.
- **Minimum payout Rs 1,500** — neeche wala balance roll over (forfeit
  kabhi nahi jab tak active hai).

### Rules (affiliate signature required — photo on WhatsApp enough)
1. **DRAP:** cure/ilaj/treatment claim kabhi nahi. Allowed: "purane jalne ke
   daag halke karne mein madadgar". Banned: "zakham ka ilaj", "100% khatam",
   "shifa", "guarantee". Ek violation = termination.
2. "**Halal certified**" kabhi nahi (koi certification nahi). Allowed:
   "halal-conscious brand".
3. No fake reviews / borrowed before-after / edited screenshots.
4. Official prices only; code = Rs 150 off bas; paisa khud collect nahi
   karna — sab COD ya store ko direct.
5. No spam (bulk WhatsApp strangers ko, auto-DMs, comment flooding).
6. Code coupon-sites par nahi, self-purchase farming nahi.
7. Independent promoter — "GlowHalal" naam ka page/account nahi banana.
8. Rule toota = code deactivate same day + unpaid commission forfeit.

### Starter kit (har affiliate ko WhatsApp folder)
- Unka code + deal ki 1 line
- 6–8 pre-approved photos + 1 short video
- 3 ready Roman-Urdu captions (DRAP-safe, doc mein template)
- 1-page Do/Don't sheet (yehi agreement bhi hai)
- Price/logistics card (Rs 1,800/3,000, ship Rs 300, free >5k, COD, 2–5 din)
- UTM link + yaad-dihani: "commission sirf code wale orders par"

## 3. Scam red flags (Pakistani reseller space ka sab se bara masla)

- **Aapse paise mange** — registration/joining fee, "ad budget", 5–10 free
  bottles "testing ke liye" → scam. Phase-0 affiliate ka upfront cost sirf
  1 sample bottle hai, wo bhi proven creator ko.
- **Guaranteed sales** — "100 orders pakka, bas advance commission dein" →
  advance hi maqsad hai.
- **Fake proofs** — edited JazzCash/courier screenshots, "customer ne mujhe
  pay kar diya, free ship kar dein".
- **Order-then-refuse burst** — apne circle se fake COD orders; delivered-only
  rule se Rs 0 milta hai; 3+ refusals ek code par = deactivate.
- **Customer data mange** — leads list, phone numbers, "admin access" →
  kabhi nahi.
- **Dealer-rate white-labeling** — khud paise collect karna ya "GlowHalal"
  page chalana = impersonation, decline.
- **Vanity followers** — 100k followers, 30 likes = bought. Engagement >1–2%
  + account age check.
